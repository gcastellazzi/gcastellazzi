### 🔭 Research & code

Existing buildings are geometrically irregular, materially heterogeneous, and rarely documented. My work bridges the gap between survey data — point clouds, CT scans, and photogrammetry — and finite element analysis, developing the masonry constitutive models, shell formulations, and error estimators these structures need.

| Project | Description |
|---|---|
| [**Cloud2FEM**](https://github.com/gcastellazzi/Cloud2FEM) · [Portable](https://github.com/gcastellazzi/Cloud2FEM-portable) | From point-cloud slicing to geometry reconstruction and analysis-ready voxel meshes. Python. |
| [**GCEEFEM.jl**](https://github.com/gcastellazzi/GCEEFEM.jl) | Gram-Channel Error Estimator: a priori error estimation for finite element solutions. |
| [**SAPT**](https://github.com/gcastellazzi/SAPT) | Abaqus through Python: pre-processing, parametric studies, and results extraction. |

👯 I collaborate with Petr Krysl at UC San Diego on shell and plate elements, contributing to [**FinEtoolsFlexStructures.jl**](https://github.com/PetrKryslUCSD/FinEtoolsFlexStructures.jl).
