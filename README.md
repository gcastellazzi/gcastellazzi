### 🔭 What I work on

Existing buildings are geometrically irregular, materially heterogeneous, and rarely documented. Standard modelling pipelines often assume otherwise.

My work aims to close that gap: turning survey data — point clouds, CT scans, and photogrammetry — into finite element models for structural analysis, and developing the masonry constitutive models, shell formulations, and error estimators those models need.
